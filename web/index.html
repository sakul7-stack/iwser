3D Engine

OpenGL-based 3D Model Viewer

Download Windows ZIP

How to Run

  1. Extract the ZIP file.
  2. Run ComputerGraphics.exe.
  3. Keep the executable, assets, shaders, and DLL files in the same folder.

Controls

  • Right Mouse Drag — Orbit camera
  • Left Mouse Drag — Rotate model
  • Mouse Wheel — Zoom
  • W A S D / Q E — Move camera
  • Z / X — Scale model
  • F — Toggle wireframe
  • R — Reset view

Supported Formats

  • GLB
  • glTF
  • OBJ
  • FBX
  • DAE
  • STL
  • PLY
  • 3DS

Technology

  • OpenGL
  • GLFW
  • GLM
  • Assimp
  • Dear ImGui
